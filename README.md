# VOID CITY — ULTRA MEGA EDITION

Telegram Mini App game: city building, production, virtual economy, quests, achievements, clans, safe PvP, leaderboard, districts, inventory and daily rewards.

Developer: @hiddenvoicer

## Important
This build uses virtual in-game currency only. There are no bets, cash-out, crypto trading, or gambling mechanics.

## Run
1. Copy `.env.example` to `.env`.
2. Put your BotFather token into `BOT_TOKEN`.
3. Install: `pip install -r requirements.txt`
4. Start: `uvicorn app:app --host 0.0.0.0 --port 8000`
5. Set the BotFather Mini App/Menu Button URL to your server URL.

The backend serves the Mini App itself, so you do not need to upload the frontend separately to a static-only host.
